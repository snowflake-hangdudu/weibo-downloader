微博内容下载与备份助手 · 隐私政策

最后更新：2026-08-23 · 版本 1.0.0 · 常见问题

本扩展（「微博内容下载与备份助手」）由个人开发者提供。我们重视您的隐私。本政策说明本扩展如何处理信息。

1. 我们收集哪些数据

我们不收集、不存储、不上传、不出售任何个人数据。

  • 不收集姓名、邮箱、微博账号或密码
  • 不把微博正文、图片、视频或下载地址发到开发者服务器
  • 不使用分析 / 追踪 SDK
  • 不含第三方广告网络；可能展示开发者公告与合作说明（静态 JSON 文本）

2. 本地处理说明

本扩展仅在您访问 weibo.com / m.weibo.cn / s.weibo.com 时运行。识别当前微博、读取媒体与保存文件均在您的浏览器本地完成。文件保存到本机浏览器默认下载目录。

若您已登录微博，扩展会使用浏览器里已有的登录状态，向微博官方页面或接口请求您当前已经能看到的内容。Cookie 与登录态不会被上传至开发者或任何第三方服务器。

3. 权限用途

  • activeTab：在当前微博页打开面板并识别您正在看的那条微博
  • downloads：把您主动选择的正文、图片、视频保存到本机
  • offscreen：在扩展内部为已读取的文件生成本地下载地址
  • storage：仅在本地缓存公告 / 合作说明等极少内容
  • declarativeNetRequest：仅为微博官方图床 / 视频 CDN 补上 Referer: https://weibo.com/，不改写 Cookie，不伪造身份
  • weibo.com / sinaimg.cn / weibocdn.com：访问微博页面与官方媒体地址，完成您主动发起的保存
  • 配置站点：仅读取公开的公告与合作说明 JSON，不上传您的微博内容

4. 远程代码

本扩展为 Manifest V3，不加载、不执行任何远程托管代码。所有脚本均包含在扩展安装包内。扩展可能请求公开 JSON，仅用于展示公告与开发合作文案。

5. 数据共享

我们不会与第三方共享用户数据，因为我们不收集用户数据。

6. 合规使用

本扩展仅供个人学习、备份自己有权访问的公开内容。请仅保存您已经能在页面上看到的微博。请勿用于侵犯版权、绕过登录 / 权限限制，或违反微博用户协议的行为。下载与使用后果由用户自行承担。

7. 政策变更

若本政策更新，将在本页面修改「最后更新」日期。重大变更时，我们可能通过扩展更新说明或商店页面告知。

8. 联系我们

如有隐私相关问题，请发邮件至 hangdudu0@agent.qq.com 联系开发者。
